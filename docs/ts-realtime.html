🔵 Info

SseEmitter.send() 시 IOException (Broken pipe)

java.io.IOException: Broken pipe / connection reset

클라이언트가 이미 떠난(탭 닫기 등) 연결로 서버가 전송을 시도해 발생합니다. 흔하고, 정상적인 정리만 잘 하면 됩니다.

  • 클라가 떠난 연결로 전송
  • emitter 정리 누락
🩺진단

  2. onCompletion/onTimeout/onError에서 컬렉션 정리
  3. Broken pipe는 WARN 이하로 로깅(노이즈 감소)
🛡️
예방 — emitter 저장소를 단일 진입점으로 두고 추가/제거를 일관되게 관리.
