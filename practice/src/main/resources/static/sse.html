SSE (Server-Sent Events)

하나의 HTTP 연결을 열어두고 서버 → 클라이언트 단방향으로 이벤트를 계속 흘려보냅니다. 알림/피드/시세/LLM 스트리밍에 최적.

브라우저 내장 EventSource를 사용합니다. 연결이 끊기면 자동 재연결되는 것도 특징입니다.

이벤트 로그

서버 코드 (Spring · SseEmitter)

@GetMapping(value = "/subscribe", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public SseEmitter subscribe() {
    SseEmitter emitter = new SseEmitter(60 * 60 * 1000L);
    emitters.add(emitter);
    emitter.onCompletion(() -> emitters.remove(emitter));
    return emitter;
}

@PostMapping("/broadcast")
public String broadcast(@RequestParam String message) {
    for (SseEmitter e : emitters) {
        e.send(SseEmitter.event().name("notification").data(message)); // 단방향 push
    }
    return "ok";
}

클라이언트 코드 (EventSource)

const es = new EventSource('/api/sse/subscribe');
es.addEventListener('notification', (e) => render(e.data));
es.onerror = () => { /* 브라우저가 자동 재연결 */ };
운영 주의: 프록시 버퍼링(proxy_buffering off), 다중 서버 fan-out(Redis Pub/Sub), heartbeat. 자세한 내용은 강의 문서 05장 참고.
