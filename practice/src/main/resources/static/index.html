서버 통신 프로토콜 실습실

Spring 백엔드 개발자를 위한 인터랙티브 실습 환경입니다. 이 사이트는 여러분이 직접 실행한 Spring Boot 서버 위에서 동작하며, 각 통신 기법의 요청/응답을 화면에서 눈으로 확인할 수 있습니다.

지금 이 페이지가 보인다면 Spring Boot 서버가 정상적으로 떠 있는 것입니다 🎉 (http://localhost:8080 에서 서빙 중)

무엇을 실습하나요?

1. HTTP / REST

DUPLEX

STOMP 기반 실시간 양방향 채팅
CONCEPT

6~8. gRPC / GraphQL / 메시징

브라우저 직접 실습은 어려운 기법의 개념과 Spring 코드

실습 흐름 (추천)

  • REST부터 시작해 HTTP의 기본 요청-응답을 확인합니다.
  • Short → Long Polling으로 "서버가 먼저 못 보내는" 한계를 우회하는 과정을 체감합니다.
  • SSE로 서버 단방향 스트리밍을, WebSocket으로 진짜 양방향 통신을 경험합니다.
  • 마지막으로 gRPC/GraphQL/메시징 개념 페이지로 큰 그림을 완성합니다.

아키텍처

브라우저 (이 사이트, localhost:8080)
   │  fetch / EventSource / WebSocket(STOMP)
   ▼
Spring Boot 서버 (동일 출처, CORS 걱정 없음)
   ├─ RestDemoController     →  /api/rest/**
   ├─ PollingController      →  /api/polling/**
   ├─ SseController          →  /api/sse/**
   └─ ChatController(STOMP)  →  /ws , /app/** , /topic/**
각 실습 페이지는 이론 요약 → 인터랙티브 데모 → 서버 코드 → 핵심 정리 순서로 구성됩니다. 함께 제공되는 ../README.md 강의 문서(00~10장)와 같이 보면 가장 효과적입니다.
